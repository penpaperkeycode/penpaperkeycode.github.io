{%- comment -%} Renders one short Markdown string inline (no

wrapper) and opens its external links in a new tab. A YAML slip such as - 2026: Promoted ... (missing double quotes) arrives here as a one-entry hash; it is turned back into "2026: Promoted ..." instead of {2026=>...}. A link to a paper in Publications is written with its id from _data/publications.yml, [2024](#pub:hcx_tr), and becomes a link to that paper's current number (#pub-21); an unknown id shows a visible "??".
